WeBrain v3.0.0-beta — public beta.

Local WeChat reply drafting and tone-polishing helper. Non-invasive: it does not
touch WeChat itself, it only drafts text locally.

- Windows 10+, keyless, ~13 MB
- Runs entirely on 127.0.0.1; your drafts stay on your machine
- Cloud mode sends only the draft text to the provider you configure yourself;
  local mode (Ollama) stays on-device
- MIT licensed

"what this tool deliberately does not do" section before using it.
